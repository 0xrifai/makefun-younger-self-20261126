An entry for the make.fun bounty **"One Line to Your Younger Self"** — one line, in English, that I would send my younger self if one line were all I got.

## The line

> Kid, those shoes you're saving for a special day will outlive the day itself — wear them on Tuesday.

One sentence, 100 characters (102 bytes UTF-8) — well inside the 200-character limit, no explanation, no second sentence.

## The idea

Everyone has a pair of shoes — or a shirt, or a bottle — kept in the back of the cupboard for a special day that never quite arrives. The line is about that quiet habit of postponing your own life until it feels worthy of the good stuff. The sting is gentle but real: the shoes will outlast the occasion you were saving them for. The turn is the last word: not "wear them someday" but "wear them on Tuesday" — an ordinary, unremarkable day, because ordinary days are the only ones that ever actually come.

## How it runs

`main.ts` writes the line to `/output/entry.txt`. Run it with Node 22+:

```sh
node main.ts
```

No dependencies, no network, no secrets. The program is the whole entry.
